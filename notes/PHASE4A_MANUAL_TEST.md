# Проверка Phase 4A в Elden Ring 1.17

Статус: **IMPLEMENTED — RUNTIME VALIDATION REQUIRED**.
Проверяется одиночная запись position/orientation. Воспроизведение ERPLAY в игре ещё не включено.

1. Закрой Elden Ring, его старый YAFSML/launcher и все экземпляры `EldenRingTheaterMode.exe`. Старый host занимает sample pipe и F6. DLL нельзя выгружать/заменять внутри запущенной игры.
2. Release уже подготовлен в `C:\Users\user\Documents\Codex\2026-10-04\outputs\EldenRingTheaterMode\Phase4A`: `EldenRingTheaterMode.exe` и `TheaterMode.dll`. Для повторной сборки из checkout выполни `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Phase4A.ps1`. Скрипт собирает host/DLL, запускает тесты и готовит отдельную конфигурацию. Запускай его из `C:\Users\user\Documents\ChatGPT\elden ring theater mode\EldenRingTheatreMode-phase4`.
3. Используй именно новую DLL из `Phase4A`: host автоматически выбирает `TheaterMode.dll` рядом со своим EXE. Старая `YAFSML.ini` и стабильная DLL не заменены. Не загружай обе версии одновременно.
4. Сначала запусти `Phase4A\EldenRingTheaterMode.exe`. Заголовок окна: `Elden Ring Theater Mode — Phase 4A write probe`. При отсутствии игры probe должен быть OFF, кнопка недоступна.
5. В этом же окне нажми **START ELDEN RING**. Host проверит свои pipe/F6, наличие EXE/DLL/INI, AMD64 и общий профиль EldenRing_1_17 (путь, file/product version 2.7.0.0, SHA-256 файла на диске). Затем создаст `%LOCALAPPDATA%\EldenRingTheaterMode\launch\YAFSML.ini` и запустит установленный `C:\Users\user\Desktop\YAFSML-v0.10.4\YAFSML.exe`. Его DLL и настройки берутся из текущей установки; отдельный CMD для обычного запуска больше не нужен. Если YAFSML перемещён, сначала выбери его EXE кнопкой **YAFSML...** — путь сохранится. Самостоятельно второй `eldenring.exe` не запускай. Используй тот же установленный offline/modded режим. Закрытие host не закрывает игру; для нового DLL-сеанса перезапусти игру через этот host.
6. Загрузи того же персонажа/сохранение, которым записывался `replay_2026-10-05_022417.erplay`, и встань на ровном открытом участке с запасом места в стороны. Название карты/сохранения не содержится в текущем ERPLAY, поэтому оно не может быть определено программой. Для этой пробы записанные координаты вообще не используются: сдвиг считается от твоего текущего положения. Дождись `Player: FOUND`, `Control IPC: CONNECTED`, `Runtime: READY`. Если написано `F6 unavailable`, закрой другие hosts и перезапусти этот host, затем игру в указанном порядке.
7. TEST 1: с probe OFF походи/повернись 5–10 секунд. Поведение должно быть обычным. Остановись. Никакие трансформы без команды не записываются.
8. TEST 2: оставь персонажа неподвижным, щёлкни **PROBE +0.5 X (ONCE)** один раз. Следи за небольшим смещением (мировая X, не обязательно вправо относительно камеры). Программа записывает только один transform и затем наблюдает две секунды; не удерживает персонажа. Ориентация сохраняется прежней, видимого поворота от этого теста ждать не нужно.
9. Через две секунды ожидай `OFF (COMPLETE)`. Нажми **F6** либо **PROBE STOP / F6**, затем походи и повернись. Нормальное управление должно работать. STOP не телепортирует персонажа обратно. Отдельно можно повторить одну пробу и сразу нажать F6, чтобы проверить отмену; небольшое смещение, если запись уже началась, STOP не отменяет. Не продолжай к hold/полной записи без анализа результата.
10. Сообщи: запустилась ли игра кнопкой, был ли виден сдвиг, остался ли он или персонаж отскочил назад, остались ли нормальными земля/коллизия/управление, сработал ли F6, был ли crash. При любой ошибке пришли логи: `%TEMP%\TheaterModeGame.log`; `%LOCALAPPDATA%\EldenRingTheaterMode\logs\TheaterModeRecorder.log`; `%LOCALAPPDATA%\EldenRingTheaterMode\launch\log\YAFSML.log`. Последнюю папку открывает **OPEN LAUNCH LOGS**. В recorder log нужны строки `LAUNCHER`, в game log — `PHASE4A`, `PROBE_WRITE_A`, `PROBE_NEXT_CALLBACK`, `PROBE_STATE`, `PROBE_STOP`, а также последний запуск с PID/проверкой профиля.

Если `PROBE_WRITE_A` показывает записанное значение, но `PROBE_NEXT_CALLBACK` возвращает исходную position или визуальная модель не сместилась, это результат теста A, а не доказательство рабочего replay. Следующий шаг — отдельная проверка документированных proxy sync flags закреплённой ревизии.
