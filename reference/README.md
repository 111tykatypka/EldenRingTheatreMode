# Reference material

`EldenRing_CameraTools_v1018/` (local only, git-ignored): Otis_Inf's injectable camera for Elden Ring
(IGCS based, v1.0.18). Proprietary, distributed through Patreon, no source code and no license that
allows reuse. Theater Mode uses it only as a behaviour reference (what a good free camera and camera
path feel like). No code is copied from it, and any game offsets Theater Mode uses are found and
verified independently against the game, then stored in GameProfile.
